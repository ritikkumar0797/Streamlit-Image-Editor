# Streamlit-Image-Editor
The Streamlit Image Editor is a web app built with Python, Streamlit, and Pillow (PIL). Users can upload images, apply real-time edits like brightness, contrast, sharpness, and color, perform operations like rotate, flip, blur, resize, and download the edited image with side-by-side preview

Streamlit Image Editor
Project Overview

The Streamlit Image Editor is an interactive web application built using Python, Streamlit, and Pillow (PIL). It allows users to upload images from their device, perform real-time edits, and download the final edited image. The editor is simple, user-friendly, and provides instant visual feedback with side-by-side comparison of the original and edited images.

Features

Upload images (PNG, JPG, JPEG) from local devices.

Real-time image adjustments:

Brightness

Contrast

Sharpness

Color enhancement

Image operations:

Rotate 90°

Flip horizontally

Blur

Emboss

Edge enhancement

Reset to original

Resize images with custom width and height.

Side-by-side preview of the original and edited images.

Download edited images directly to the device.


Install required Python packages:

pip install streamlit pillow


Run the Streamlit app:

streamlit run app.py


Upload an image from your device using the file uploader.

Use the sidebar to adjust brightness, contrast, sharpness, and color.

Click operation buttons to rotate, flip, blur, emboss, enhance edges, or reset the image.

Resize the image by entering width and height and clicking Apply Resize.

Preview the original and edited images side by side.

Download the edited image using the Save Edited Image button.

Dependencies

Python 3.7+

Streamlit

Pillow (PIL)
